Nusantara Sky Courier is an original offline flight game for the make.fun bounty [Make the best flight game](https://make.fun/bounty/best-flight-game-20261126-0057) ($500 USDC, 50 paid places). You fly a small courier plane, PK-NSC, across a seeded Indonesian archipelago in a chase view over recognisable island terrain, with the aircraft in frame, instruments lit, and altitude, speed and heading on the HUD.

Three sorties, each with a different goal: **Ring Run** (fly through 5 golden rings over the sea), **Island Hop** (land on the airstrips of Pulau Komodo and Pulau Banda), and **Storm Courier** (deliver the parcel to Pulau Banda through gusting wind before the fuel runs out). Throttle and turn discipline matter — fuel burns, the hull takes damage from hard landings, and a stall will drop you into the sea. Keyboard and mouse: arrow keys pitch and bank, W/S or Shift work the throttle, G lowers the gear, F the flaps, mouse steers, holding click adds throttle.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network request — every file the game loads lives under `game/`.
